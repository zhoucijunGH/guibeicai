# 桂备菜 · 功能说明文档

> 覆盖 v1.5.0 全部功能页面。所有页面需登录后访问；商家仅见授权门店数据。

## 工作台首页（app.py）
- 核心指标卡：累计预测次数、预估营业额、食材成本、平均毛利率。
- 近期预测记录表 + 预估营业额趋势图。
- 快捷入口：数据上传 / 执行预测 / 食材预测 / 采购单 / 预测对比 / 损耗分析。

## 数据上传（1_数据上传.py）
- **批量导入**：上传含「销售数据」「菜品用料表」两个 Sheet 的 Excel；自动校验列名、门店匹配、补录 recipes。
- **每日销量录入**：按门店+日期补录实际销量（默认昨日，可补近 7 天），三级兜底（已录入 > 预测 > 历史）。
- 提供下载数据模板。

## 执行预测（2_预测配置.py）
- **手动预测**：选定门店与预测日 → 调用 Prophet + LLM 备菜建议 → 落库。
- **自动预测**：APScheduler 每日定时跑（可在配置中改小时）。
- 产出含菜品预测份数、食材采购明细、风险等级、采购建议。

## 预测总览（3_预测总览.py）
- 按门店/日期筛选历史预测，表格展示财务指标。
- 点击行查看预测详情：营业额/毛利率、风险等级、采购建议、采购明细，可导出 CSV。

## 食材级预测（12_食材预测.py）★新增
- 读取最近一次预测 → 按 `recipes` 把菜品份数聚合到食材维度。
- 展示食材需求明细（分类/用量/单位/预估成本）+ Top15 成本柱状图 + CSV 导出。

## 采购单生成（13_采购单.py）★新增
- 一键基于最近预测生成采购单：食材种类、采购数量、预估金额、供应商占位列。
- 可直接导出 CSV 发给供应商或导入 ERP。

## 门店管理（4_门店管理.py）
- 增/改/删门店，启停状态；操作记审计。

## 菜品管理（5_菜品管理.py）
- 按门店查看菜品，启用/停用（停用菜品不参与预测）；操作记审计。

## 预测对比（9_预测对比.py）
- 单店单日：预测 vs 实际销量对比，量化偏差，持续校准模型。

## 模型回测（10_回测.py）
- 时间序列 hold-out 回测，输出 MAE / MAPE / RMSE / bias。
- 一键应用偏差校正因子到下次预测（误差反馈闭环）。

## 损耗分析（16_损耗分析.py）★新增
- 基于 `actual_sales`（实际销量/损耗）按区间统计：总损耗量、综合损耗率、损耗成本。
- 菜品损耗排行 + Top15 损耗成本图 + CSV 导出。

## 智能预警（15_智能预警.py）★新增
- 规则引擎触发四类预警：
  - **加备**：预测 > 1.3× 历史均值；
  - **减备/滞销**：预测 < 0.7× 历史均值；
  - **节假日备货**：未来 3 天含法定节假日；
  - **偏差复核**：实际与预测偏差 > 30%。
- 支持"标记已处理"。

## 系统管理（仅 admin）
- **用户管理（7）**：增删改用户、绑定门店、改密码；记审计。
- **角色管理（8）**：角色与权限配置。
- **操作审计（11）**：按动作/用户/日期检索全部操作日志。

## 设计系统
- 明/暗双主题（侧边栏一键切换），统一品牌色板与组件库（指标卡/风险标签/区块/空状态/横幅/分步向导）。
